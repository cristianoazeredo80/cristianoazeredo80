### Sobre

Cuido da operação e da automação de uma frota de servidores Windows distribuída em mais de 130 lojas de varejo e fast-food. Meu trabalho vai de scripting de endpoint e distribuição via RMM até padronização de hardware, monitoramento e resposta a incidentes em ambiente de PDV.

### O que eu faço

- **Automação de frota:** empacotamento e distribuição de scripts PowerShell via ITarian, contornando restrições de Execution Policy, agentes de 32 bits e corrupção de variáveis em transporte
- **Ferramentas internas:** serviços Windows escritos em Go para posicionamento de janelas de PDV, monitoramento de roteadores e watchdog do agente de RMM
- **Padronização:** configuração de BIOS em Dell OptiPlex com Dell Command | Configure, sincronismo de relógio via NTP, coleta de inventário de hardware e software
- **Observabilidade:** captura de eventos Kernel-Power e despacho por API
- **Redes:** provisionamento e diagnóstico de roteadores Intelbras, DHCP, IP fixo e links de loja
